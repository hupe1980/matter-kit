These guides explain the protocol as well as the crate. Matter is a large specification and
most of its surprises come from rules that read like boilerplate, so each page states the
rule, cites the section it comes from, and says what breaks when you get it wrong.

The per-item API reference lives on [docs.rs](https://docs.rs/matter-kit); what is built and
what is not is on the [status page](@/docs/status.md), and
[which specification sections this crate names](@/docs/coverage.md) is generated from the source
rather than written.

**New to Matter?** Start with [Matter in ten minutes](@/docs/matter-in-ten-minutes.md).
**Here to build something?** Start with [Getting started](@/docs/getting-started.md).
